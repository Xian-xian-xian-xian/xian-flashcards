# 网站开放前安全与数据可靠性检查

检查日期：2026-10-15（北京时间）。覆盖番茄基地、闪记卡和番茄经营共用后端，以及线上 Nginx、数据文件权限、备份与自动启动。

## 结论

本次检查发现的问题已完成应用修复并发布。建议先向少量受邀伙伴开放试用。邀请码仍为服务器校验，已有账号继续正常登录。

这是一轮源码审查、依赖漏洞扫描、隔离环境攻击/故障回归及低流量线上验收，不能证明不存在未知漏洞，也不等于大规模压测或独立第三方渗透测试。

## 发现与处理

| 问题 | 可能影响 | 已采取的措施 |
| --- | --- | --- |
| 数据库直接覆盖写入 | 进程中断或写入失败可能损坏原文件；失败的内存修改还可能混入后续保存 | 同目录临时文件、文件同步、原子替换；保存失败回滚到上次持久化数据；权限 600 |
| 番茄状态缺少服务器版本校验 | 旧页面、多设备操作覆盖新记录 | 每账号版本号；旧版本返回 409；异常批量减少返回 422；明确确认的导入/清空仍可执行 |
| 缺少稳定的恢复路径 | 同步误覆盖后难以找回 | 每账号保留最近 20 份番茄状态历史；每小时校验数据库并备份，保留最近 168 份；图片单独增量备份 |
| 普通账号可下载全站近期日志 | 其他用户的请求信息、IP、部分调试信息可能暴露 | 仅管理员可下载；普通用户返回 403 |
| 番茄导入/同步数据的编号未转义 | 特殊编号或记录序号可能形成 HTML 注入 | 编号、属性值及序号转义；去除危险原型字段；导出 CSV 的公式开头加安全前缀 |
| 无法识别归属的旧浏览器数据可能进入新账号 | 同一浏览器换账号时可能串入旧数据 | 未知归属数据只保留本地备份，不自动上传到新账号 |
| 上传与表格解析资源缺少充分限制 | 恶意文件、压缩包或大量请求拖慢服务 | 升级文件处理组件；解析移到独立进程；128 MB JS 堆、10 秒超时；检查 XLSX 解压规模；每次最多 5000 行 |
| 请求、存储及外部语音请求缺少全局边界 | 刷接口、堆积文件、消耗语音额度 | IP 与账号限流；大请求解析前验证登录；图片额度；卡片额度；语音并发、全局额度与超时 |
| 卡片编辑的版本检查不严格 | 缺少版本或伪造未来时间可覆盖较新编辑 | 内容编辑要求精确匹配服务器版本；明确选择覆盖时仍允许强制保存 |
| 多条数据库修改未全部放在事务内 | 部分删除、导入撤销、旧数据迁移中断时可能出现不一致 | 创建卡片、删除卡组/卡片、批量删除、导入撤销、首次旧卡归一化等集中提交 |
| 已知漏洞依赖 | 涉及上传、表格、代理地址识别及开发工具链等风险 | 更新并固定兼容补丁；SheetJS 使用官方发行包；KaTeX 网页资源同步更新；最终全依赖扫描为 0 项已知漏洞 |
| 缺少若干 HTTP 防护 | 跨站写入、嵌入诱导、配置文件探测及请求洪泛 | 来源与内容类型校验；错误响应不返回堆栈；Nginx 限流、CSP、HSTS、nosniff、敏感隐藏路径阻断 |

## 已启用的边界

- 注册仍需有效邀请码；没有有效邀请码不能创建账号。
- 单次导入最多 5000 行，文件/粘贴内容最多 10 MB；XLSX 解压总量最多 32 MB、单项最多 16 MB。
- 每账号图片空间最多 256 MB、5000 个文件；每小时最多 120 次图片上传和 12 次表格导入尝试。
- 每账号卡片最多 10000 张或 32 MB 文本；全站卡片文本上限 64 MB；单张提交最多 256 KB。
- 番茄状态提交最多 8 MB；各数据列表最多 20000 项。
- 新语音合成每账号每小时最多 120 次、全站每小时最多 500 次、同时最多 4 项；缓存命中不消耗新合成额度。
- 每账号最多保留 20 个登录会话，过期会话会被清理。

这些限制是当前小型服务器的保护边界，容量需求增长时应先评估数据库和存储，再调整额度。

## 仍需保留的运维要求

1. 自动备份目前在同一台服务器上。本次已额外留存一份本机副本，但尚未配置持续自动异地备份；服务器/云盘整体丢失后的恢复能力仍取决于最近的异地副本。
2. 当前 sql.js 架构只能有一个后端写进程。不能直接改成 PM2 cluster、多实例或多机器共同写同一个数据库文件。
3. 本次没有进行高流量或破坏性公网测试，没有核验阿里云账号 IAM、云安全组、云快照、WAF 或网络层 DDoS 防护，也没有进行主机入侵取证。
